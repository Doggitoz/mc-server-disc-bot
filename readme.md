# How to setup
1. Download the files as a zip and extract in destination of choosing
2. Install Python 3.13
3. Run the py file generate_env_file.py. This will either update your current file or create a new one with all necessary env values
4. Install python dependencies located in requirements.txt - through either .venv or system default
5. Run the relevant .bat or .sh file depending on whether you are running linux/windows or venv/system
